# 立项之前

在立项之前呢，我曾经试过搭建网站。
## 第一次建站经历
记得那还是在 GPT 还没普及的时候，我一时兴起就想试着建个站玩玩。按照网上的教程，我注册了一个虚拟主机的提供商（我记得是 HostFree），然后去某某二级域名分发网站上拿了一个域名，又去某模板网站上下了一个看起来还行的模板。当时还是古法编程，我用手机软件 `AIDE Web` (一些基础知识我是在这学的） 照着模板改，最终上传到虚拟主机上完成建站了（就是速度慢了点）。

## 第二次建站经历

感觉这不算第二次。第二次我是用内网穿透做的。这次就是本地`KSWEB + ngrok`部署的，缺点就是这样做手机耗电量极大，而且后台进程容易被Kill。之后因为虚拟主机国内连接困难，内网穿透要实名（花生壳、Sakura FRP），就没怎么折腾网站了。

## 之后

之后配了电脑，有条件了。我第一个和现在用的就是 Nginx，因为它简洁、轻量。

得益于之前的经验，我萌生了搭建网站的想法。嗯不对，我建站之初纯纯是为了好奇。<br><br>我当初是好奇蔚蓝档案的 UI 设计风格是啥，就问了下<span class="hover-hint">蓝色大肥鱼<span class="hover-hint__tooltip"><span class="hint-title">蓝色大肥鱼</span>“蓝色大肥鱼”是 DeepSeek在中文互联网上最出圈的拟人化爱称，指代一只贪吃、爱摸鱼、有“活人感”的蓝色鲸鱼少女形象。</span></span>。感觉它说的不是很详细，之后我用另一个 AI 生成了风格介绍，又用 DeepSeek 整合，总结了一篇 Markdown 文档……要不生成一篇 UI 设计规范？就是这么巧，在一步一步地我就让 DeepSeek 生成了我的个人主页。

# 项目成立

哎呀都做出来了怎能不做版本控制，用版本控制怎能不连接远程仓库。OK 干它！于是从军训后几天到昨天没一天是闲着的（昨天是 2026-10-06），我的国庆假期啊……

## 网页开发
### 个人主页
这个没什么好讲的。我只要复制粘贴就好了，而蓝色大肥鱼要考虑的可就多了。主页界面我参考了下游戏 UI 和一些模仿项目，做了一套还看得过去的 UI。当时思考如何布局时就和我现在写水文一样深思熟虑。但最终还是做出来了，不是吗？因为服务器成本原因，PNG 素材被压成 WebP，又被压成 AVIF，图标干脆重画成 SVG。ICO 的网页图标直接换为 SVG 了。

### 七七的折腾笔记
再想想，我还是往里面写点内容吧，我看你们都这样。才……才不是备案不让这么起名呢。我依旧仿游戏风格让 AI 生成网页，因为没后端，我就静态配置了每个页面。DeepSeek 说如果需要切换页面（不新建标签页）而不停止音乐播放，需要重构网页。呃，就这样挺好的。

### 笔记页面
我啊，依旧延续用静态页面的传统。写好 Markdown 就让 Python 处理成 html，可方便了（但后期维护不方便）。因为是静态页面，点赞、评论是没有的。就连账号都注册不了（SSH 除外）。

# 服务器购置
我之前用过阿里云的 `云解析 DNS` 中的 `移动解析HTTPDNS`（DoH），所以建站时我用的阿里云。在我稍微了解方法后，我开始考虑是用**虚拟主机**还是**云服务器 ECS**。结果我发现在**虚拟主机**、**轻量应用服务器**和 **ECS** 中，就 **ECS** 最便宜。在选购期间，阿里云客服居然还给我来电了，只因为我跟在线人工客服咨询过（就发了一句话），它向我推荐了一年 99 元的 ECS。很快啊，我就放弃了之前考虑的 ECS 配置，拥抱了便宜套餐。

# 域名备案
买了服务器，怎能少了域名呢？在朋友的推荐下，我从更便宜的 `.top` 和便宜的 `.cn` 域名中选择了 `.cn` 域名，并以我的网名注册为域名前缀。注册域名时的速度很快啊，不到一天就注册下来了。之后就是 ICP 备案了。听阿里云客服说我们这边备案可能要 20 天左右。我的天啊，为什么这么慢。但令我惊讶的是，10 月 3 日提交的到 10 月 10 日就通过了。

# 网站上线

收到邮件那晚，我直接说如果网站没上线我就不睡了。可结果实际上我睡觉的时间是 1:40（还有早八呢，可爽了呢~）。

上线占了 10%，配置服务器用了 90% 的时间。我差点被阿里云的 **边缘安全加速 ESA** 整破防了（强者抱怨环境；但我是弱者，我不仅抱怨环境，我还抱怨强者。）。设置了一堆东西，甚至这个功能还免费帮我从 **Let's Encrypt** 那申请了SSL证书用于ESA。就是有个缺点：SSL证书无法导出啊，我还得自己再申请。

ESA 这东西，说好听点叫边缘安全加速，说难听点叫“我明明只想上线，你却让我重新学一遍网络”。
域名接入、CNAME、回源、缓存、SSL/TLS、强制 HTTPS、HSTS……每一项看起来都能默认，每一项默认完都可能有惊喜。

还好有点经验，至少看控制台不像飞机的仪表盘。
