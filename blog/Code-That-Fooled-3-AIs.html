代码一定要能跑XX一定要XX（梗）“XX一定要XX”这个梗，本质上是网络“将军梗”的核心句式，主要用来调侃或讽刺将理所当然的常识，包装成“重要指示”来说的“废话文学”。
它起源于中文互联网对朝鲜相关宣传视频的二次创作和解构。在这些视频里，“将军”经常在视察各行各业时作出“指导”，似乎对任何事情都了如指掌。网友们于是抓住这种“什么都懂、什么都要指导”的观感，创造了这个句式来调侃：仿佛“将军”对着任何事物，都能发表一番看似重要、实则无比正确的“指示”。
这个梗的用法非常简单，精髓在于用极其严肃的语气，说一句绝对正确但毫无信息量的废话。

第一行 int

首先来看第一行，这个int; a = 5;中的分号表示的是分割符，就相当于：

python 
int
a = 5
NOTE

Python 看到 int 会去“查这个名字是谁”、查完算出一个结果、但脚本不会自动把结果打印出来。

单独执行 int 是这样的：

python 
>>> int
<class 'int'>

简单的说就是Python在执行这个指令的时候，直接把返回的内容扔掉了（不是print或赋值赋值把某个值绑定给变量，例如 a = 5 表示让变量 a 指向整数 5。）。
